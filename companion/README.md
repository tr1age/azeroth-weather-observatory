# Companion setup

Download the Windows installer or the matching Mac ZIP from GitHub Releases. Windows uses a single executable; opening it lets you install and enable sharing or stop sharing later. Extract the Mac ZIP and open the install or stop command. The downloads are unsigned and the Mac downloads are not notarized.

After opting in, use /reload or log out to let WoW save the addon's data. The companion uploads saved observations and downloads the latest community snapshot. Reload WoW again to see that snapshot. Only data described in the repository README is sent.

Windows uses the standard Program Files (x86)/World of Warcraft/_forever_ location; Mac uses /Applications/World of Warcraft/_forever_. Custom paths are not yet supported by the packaged installers.
