# Azeroth Weather Companion

A small opt-in companion for Azeroth Weather Observatory. The addon saves weather observations during logout or UI reload; the companion uploads them and downloads the community feed. It sends weather, zone, realm, time, source, optional intensity, and a random installation ID. It does not send character or account names. Reports are public.

This repository currently builds test Mac installers for Apple Silicon and Intel. The installers are not signed or notarized. The companion and addon are independent of Blizzard Entertainment.
